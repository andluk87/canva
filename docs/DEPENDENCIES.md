# Прямые зависимости

Полные зафиксированные версии и транзитивные пакеты: package-lock.json. Лицензии зависимостей не передают права на товарные знаки или загружаемый пользователями контент.

| Зависимость           | Назначение                 | Лицензия                   |
| --------------------- | -------------------------- | -------------------------- |
| React / React DOM     | UI                         | MIT                        |
| Fabric.js             | Рендеринг и редактирование | MIT                        |
| Express               | HTTP API                   | MIT                        |
| Multer                | Загрузка файлов            | MIT                        |
| Sharp                 | Обработка изображений      | Apache-2.0                 |
| jsPDF                 | PDF                        | MIT                        |
| Lucide React          | Иконки                     | ISC                        |
| Node.js / node:sqlite | Runtime / БД               | MIT / SQLite public domain |
| TypeScript            | Типизация                  | Apache-2.0                 |
| Vite / plugin-react   | Сборка                     | MIT                        |
| Playwright            | E2E                        | Apache-2.0                 |

Все восемь шаблонов, композиции карточек и стили созданы специально для этого проекта. Внешние стоковые фотографии, музыка, шрифты или товарные знаки Canva не включены. UI использует системные шрифты; их наличие зависит от браузера. За права на загружаемые файлы отвечает пользователь. Список не заменяет полный аудит транзитивных зависимостей.
