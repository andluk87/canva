# Прямые зависимости — релиз 0.4.0

Полные зафиксированные версии и транзитивные пакеты: package-lock.json. Лицензии зависимостей не передают права на товарные знаки или загружаемый пользователями контент.

| Зависимость           | Назначение                                | Лицензия                   |
| --------------------- | ----------------------------------------- | -------------------------- |
| React / React DOM     | UI                                        | MIT                        |
| Yjs                   | CRDT общего документа и локальная история | MIT                        |
| ws                    | Сервер WebSocket                          | MIT                        |
| Fabric.js             | Рендеринг и редактирование                | MIT                        |
| Express               | HTTP API                                  | MIT                        |
| Multer                | Загрузка файлов                           | MIT                        |
| Sharp                 | Обработка изображений                     | Apache-2.0                 |
| jsPDF                 | PDF                                       | MIT                        |
| PptxGenJS             | Настоящий Office Open XML / PPTX, заметки   | MIT                        |
| JSZip                 | Чтение ZIP/XML в тестах PPTX               | MIT OR GPL-3.0-or-later     |
| Lucide React          | Иконки                                    | ISC                        |
| Node.js / node:sqlite | Runtime / БД                              | MIT / SQLite public domain |
| TypeScript            | Типизация                                 | Apache-2.0                 |
| Vite / plugin-react   | Сборка                                    | MIT                        |
| fake-indexeddb        | IndexedDB в Node-тестах                    | Apache-2.0                 |
| Playwright            | E2E                                       | Apache-2.0                 |

PptxGenJS загружается лениво при экспорте; генерация выполняется локально в браузере без внешнего PowerPoint-сервиса. JSZip является прямой dev-зависимостью для проверок файла и также используется транзитивными зависимостями по lockfile. Для JSZip доступен выбор лицензии MIT или GPL-3.0-or-later; здесь указано выражение лицензии пакета, а не изменение лицензии приложения.

Фото, маски, диаграммы и визуальные таблицы используют уже подключённый Fabric.js без отдельного image/chart/spreadsheet-сервиса. TOTP и шифрование используют встроенный `node:crypto`; новых внешних провайдеров для этих функций нет.

Все восемь шаблонов, композиции карточек и стили созданы специально для этого проекта. Внешние стоковые фотографии, музыка, шрифты или товарные знаки Canva не включены. UI использует системные шрифты; их наличие зависит от браузера. За права на загружаемые файлы отвечает пользователь. Список не заменяет полный аудит транзитивных зависимостей.
