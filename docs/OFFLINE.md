# Офлайн и PWA — 0.3

Откройте приложение и нужный проект с доступным сервером хотя бы один раз. После подготовки локальной копии можно отключить сеть, продолжить редактирование и перезагрузить страницу. Статус «Офлайн — сохранено на устройстве» означает завершённую запись Yjs-документа в IndexedDB. При восстановлении связи изменения отправляются через существующую совместную сессию; сервер заново проверяет cookie, доступ и роль.

Для загрузки приложения после полной перезагрузки нужен service worker: браузеры разрешают его на HTTPS и localhost. Для удалённого сервера с обычным HTTP открытая вкладка продолжает работать, но перезагрузка без сети не гарантируется. Холодный первый запуск без интернета невозможен. Создание аккаунтов и новых проектов, загрузка новых файлов, CSV, публикации, настройки безопасности и серверные версии требуют сервера.

## Что сохраняется

- Оболочка приложения, включая ленивые модули редактора и PDF, кэшируется service worker после установки. В Cache Storage не попадают `/api/*`, cookie и ответы приватных API.
- IndexedDB хранит посещённые проекты и отдельный Yjs-документ с epoch, ролью, revision и признаком неотправленных изменений. Ключи включают ID аккаунта и проекта. Список проектов может содержать ещё не открытые документы: без локальной копии они не открываются офлайн.
- Изображения, добавленные через загрузки редактора, встраиваются как data URI и доступны без повторного запроса приватного файла. Произвольные внешние ресурсы в импортированном JSON не считаются подготовленными для офлайна.
- В localStorage сохраняется безопасный профиль последнего пользователя с датой проверки, максимум на семь дней; паролей, bearer-токенов и секретов TOTP там нет. Авторизация сервера остаётся в HttpOnly cookie. Офлайн-профиль позволяет просматривать ранее сохранённые данные этого браузера и не подтверждает действующий доступ на сервере.

## Выход и ошибки

Выход очищает профиль и локальные документы аккаунта. Удаление из двух IndexedDB-хранилищ выполняется в одной транзакции. Поколение локальной сессии блокирует старые отложенные записи; ответы запросов предыдущего аккаунта игнорируются. Другие вкладки этого origin реагируют на смену/удаление профиля и закрывают старый редактор. Если выйти без сети, браузер запоминает необходимость серверного logout и выполняет его до следующего входа.

При закрытии редактора уже подготовленные локальные записи завершаются. При ошибке IndexedDB/квоты статус сообщает об ошибке, а несохранённый документ предупреждает перед выходом. Сохраняйте JSON вручную при проблемах с устройством. Очистка данных браузера, приватный режим и eviction могут удалить локальные копии: это дополнение к серверу, а не резервная копия.

После отзыва роли локальные изменения не отправляются. После несовместимой смены epoch требуется экспорт локального JSON и перезагрузка; система не перезаписывает новый серверный документ старым. Посимвольный офлайн-merge текста и перенос локальных копий между устройствами не реализованы. Локальные документы не зашифрованы отдельным ключом; для общего компьютера завершайте сеанс.

Проверки: Node-тесты проверяют сохранение после закрытия IndexedDB, изоляцию аккаунтов, очистку и отказ устаревших записей. Playwright проверяет холодную перезагрузку без сети, встроенное загруженное изображение, восстановление правок и синхронизацию; отдельно — выход из другой вкладки и запоздавший ответ предыдущего аккаунта.
