# Личные шаблоны

Раздел **Мои шаблоны** в кабинете и редакторе хранит личную библиотеку повторно используемых дизайнов. Внешние сервисы и загрузка файлов не нужны.

## Работа с библиотекой

В кабинете выберите исходный сохранённый дизайн, укажите название и необязательную категорию, затем нажмите «Сохранить шаблон». В редакторе исходником служит текущий проект: перед созданием снимка приложение сохраняет его изменения на сервере. Для этого требуется соединение с сервером.

Сохраняется самостоятельный снимок полного документа: все страницы, объекты, размеры, тип дизайна и допустимый встроенный предпросмотр. Для сохранения нужны права владельца или редактора исходного проекта. Доступ только для просмотра этого не разрешает.

Поиск учитывает названия и категории, включая русский текст; фильтр категории работает отдельно. «Использовать» создаёт новый личный проект, который можно переименовать перед открытием. Новый проект не связан с исходником: изменения в нём не затрагивают шаблон и другие проекты. Участники, комментарии, история версий, папка, избранное и состояние корзины исходника не копируются. Все изображения и другие значения документа сохраняются как часть снимка; сервер не скачивает внешние ресурсы.

«Изменить» меняет название и категорию. Чтобы заменить страницы и размеры сохранённого шаблона, включите «Обновить снимок из выбранного/текущего дизайна». Без этого действия изменения исходного проекта не синхронизируются с библиотекой. При конфликте с другой вкладкой обновите библиотеку и повторите редактирование. Уже созданные проекты сохраняют прежние документы после обновления шаблона.

Удаление шаблона не удаляет исходный проект и созданные на его основе дизайны. Сохранённый личный снимок остаётся доступен своему владельцу после удаления исходного проекта или отзыва доступа к нему; заменить снимок из недоступного источника уже нельзя.

## Ограничения

- Библиотека приватная. Совместного каталога, публикации и продажи шаблонов в этом разделе нет.
- До 100 личных шаблонов и суммарно 50 МиБ документов и предпросмотров на аккаунт. Снимок должен пройти общий валидатор проекта: 1–100 страниц, до 2000 объектов верхнего уровня на странице, размер документа менее 15 000 000 байт.
- Название: 1–200 символов, категория: до 60 символов. Управляющие символы не допускаются.
- Предпросмотр берётся из сохранённого проекта, когда это встроенный PNG/JPG/WebP до 1 000 000 символов. Внешние URL и SVG в карточке не отображаются. При отсутствии предпросмотра показывается обложка с названием; шаблон остаётся рабочим.
- Это снимок, а не связь с исходным проектом. Приватные ссылки на изображения, записанные в документ вручную, не получают новых прав доступа и могут не работать после отзыва доступа к этим ресурсам. Изображения, загруженные через обычный редактор, встраиваются в документ.
- Библиотека требует доступа к серверу; отдельного автономного кеша личных шаблонов нет. Созданные проекты используют существующий механизм сохранения проекта.

## API

Все маршруты требуют cookie авторизации и возвращают `Cache-Control: no-store`. Чужой ID шаблона возвращает 404.

| Метод и путь | Действие |
| --- | --- |
| `GET /api/personal-templates?q=...&category=...` | Список карточек без полного документа, категории, расход и ограничения |
| `POST /api/personal-templates` | `{projectId,title,category?}` — снимок доступного для редактирования сохранённого проекта |
| `PATCH /api/personal-templates/:id` | `{revision,title?,category?,projectId?}` — явное обновление; устаревшая версия даёт 409 |
| `DELETE /api/personal-templates/:id` | Удаление своего шаблона; можно передать `{revision}` для защиты от удаления изменившейся версии |
| `POST /api/personal-templates/:id/instantiate` | `{title?}` — `{project}` с полным документом, владельцем текущим пользователем и `role:"owner"` |

Все изменения и создание проекта выполняются транзакционно. Проверка доступа к источнику и квоты проходит внутри транзакции. Таблица `personal_templates` добавляется к существующей SQLite без изменения имеющихся пользователей и проектов; зависимости от существования исходника нет.

Проверка: `node --test tests/personal-templates.test.mjs`; браузерные сценарии: `npx playwright test tests/e2e/personal-templates.spec.ts`.
