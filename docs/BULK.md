# Массовое создание из CSV

В редакторе нажмите **«Массовое создание»**. Одна строка таблицы создаёт один самостоятельный проект с теми же размерами и страницами. Исходный дизайн не изменяется.

1. В текстовых блоках дизайна напишите переменные: `Здравствуйте, {{имя}}!`, `Город: {{город}}`. Переменные работают также в тексте внутри групп и на всех страницах.
2. Загрузите CSV UTF-8 или вставьте содержимое таблицы. Первая строка — названия столбцов без скобок. Регистр имеет значение; пробелы вокруг названий столбцов и внутри скобок переменной игнорируются.
3. Проверьте первые пять строк в предпросмотре. Кнопка «Скачать пример» создаёт пример с названиями найденных переменных.
4. При желании задайте шаблон названий, например `Приглашение — {{имя}}`. Если его не указать, проекты получат названия исходного проекта с порядковым номером.
5. Нажмите «Создать дизайны». Все созданные проекты принадлежат текущему пользователю и появляются в «Мои проекты».

```csv
имя,город
Анна,Москва
Иван,"Казань, центр"
```

Допускаются запятая и точка с запятой (определяются автоматически по заголовку), BOM, окончания строк LF/CRLF, переносы внутри ячеек в двойных кавычках и экранирование кавычек удвоением: `"Иван ""Иваныч"""`. Значения ячеек сохраняются буквально, без выполнения HTML, формул или повторной подстановки переменных из значения.

Пустая ячейка заменяет переменную пустой строкой. Неизвестные столбцы разрешены. Отсутствующий столбец для переменной в дизайне или названии вызывает ошибку до создания проектов. Число ячеек в каждой строке должно совпадать с заголовком. Названия столбцов должны быть непустыми и уникальными.

За запуск: максимум **50 проектов**, CSV до **1 МБ**, до **100 столбцов**, до **20 000 символов** в ячейке; суммарный объём документов до **30 МБ**. Название каждого проекта должно содержать от 1 до 200 символов. Больше строк можно обработать несколькими файлами.

Массовое создание доступно владельцу и редактору исходного проекта. Читатель не может его запустить. Доступ участников, комментарии, история версий, папка, избранное и превью не копируются. Текстовые переменные заменяют только поля `text`; идентификаторы, оформление и ссылки на изображения сохраняются. Подстановка изображений и создание страниц вместо отдельных проектов пока не поддерживаются. Дизайн без переменных создаёт точные копии.

## API

`POST /api/projects/:id/bulk` требует обычную сессию и право редактирования источника.

```json
{
  "csv": "имя,город\nАнна,Москва\nИван,Казань",
  "titlePattern": "Приглашение — {{имя}}",
  "mode": "projects"
}
```

`titlePattern` необязателен. Единственный режим — `projects`, он используется по умолчанию. Ответ `201`: `{ "projects": [...], "count": 2, "variables": ["имя", "город"] }`. Каждый элемент `projects` содержит созданный документ и `role: "owner"`. Создание транзакционное: если любая строка некорректна или запись в БД завершается ошибкой, весь набор отменяется. Удалённый источник нужно сначала восстановить из корзины.

Проверки: `node --test tests/bulk*.test.mjs` и `npx playwright test tests/e2e/bulk.spec.ts` при работающем приложении на `8192` (или с `TEST_BASE_URL`).
