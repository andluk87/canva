# Матрица соответствия ТЗ — релиз 0.1

Дата: 19.10.2026. Это реестр реализованного первого релиза, а не подтверждение полного соответствия Canva. Статус сценария относится к описанному ограниченному поведению. «Частично» не считается полной приёмкой пункта ТЗ.

| ID    | Сценарий             | Статус реализации            | Проверка / ограничение                                                                                  |
| ----- | -------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| AT-01 | Регистрация          | Частично                     | Email/password + вход/выход; API и E2E. Нет подтверждения email/OAuth/2FA/восстановления                |
| AT-02 | Создание дизайна     | Реализовано                  | API + E2E: стандартный и произвольный размер открываются в редакторе                                    |

## Состояния и ошибки

UI показывает ошибки регистрации, входа, загрузки, API, экспорта и сохранения. Несохранённая вкладка предупреждает перед выходом. Конфликт revision не перезаписывает данные: пользователь экспортирует JSON и перезагружает. Отсутствие сети не отображается как успешное сохранение.

## Последующие этапы

1. Завершить Core: email lifecycle, постоянное локальное хранилище, расширенные negative E2E, accessibility, восстановление бэкапов.
2. Advanced: маски, эффекты/фильтры, текстовые эффекты, SVG/PPTX, векторный PDF и серверный экспорт/очереди.
3. Collaboration: Yjs, WebSocket, курсоры/присутствие, команды/организации, invitations/email, permissions scope и аудит.
4. Billing/AI: реальные провайдеры, верифицированные webhooks, entitlements/лимиты, кредиты/квоты. Затем media/video.
5. Документы/таблицы/доски/сайты/enterprise/mobile — самостоятельные релизы по ТЗ.

## Не выполненные проверки

Нет тестирования Firefox/Safari/Edge, физических телефонов, пиксельного сравнения всех шрифтов и экспорта, нагрузочных профилей 100/500/1000 объектов, 10 realtime-участников, SLA, аварийного восстановления и оплаты. Производственная готовность полного ТЗ не заявляется.
