# Публикация снимков дизайна

Владелец открывает «Опубликовать» в редакторе и создаёт публичную ссылку.
По ней любой получатель без регистрации просматривает сохранённый снимок страниц.
Это публикация дизайна или презентации, а не конструктор сайтов: HTML-страницы,
домены, интерактивные формы и внешние скрипты не создаются.

Ссылка содержит случайный 256-битный токен. Делитесь ею только с теми, кому можно
видеть снимок. Роль участника «Просмотр» или «Редактор» сама по себе не делает
проект публичным. Создавать, обновлять и отзывать публикации может владелец.

Редактор сохраняет проект перед открытием панели публикации. Последующие правки
в приватном проекте не меняют публичный снимок автоматически. Кнопка «Обновить
снимок» сохраняет новую версию под той же ссылкой; старые записи снимков в БД
остаются неизменными. Новый получатель видит последнюю явно опубликованную версию.
Срок ссылки задаётся при создании и обновлении: 1, 7, 30 дней либо без ограничения.
Сервер также принимает срок до 365 дней. Время вычисляется сервером.

«Отозвать ссылку» требует отдельного подтверждения и немедленно прекращает новые
обращения к ней. Восстановить отозванный токен нельзя, можно создать новую ссылку.
Уже загруженная в браузер страница, скачанный или скопированный получателем снимок
не удаляются удалённо. При помещении проекта в корзину или окончательном удалении
публичный доступ также прекращается. При окончательном удалении связанные снимки
удаляются каскадно.

## Приватность и безопасный просмотр

Публичный ответ содержит только название, тип, размеры, номер публикации и страницы
снимка. Email владельца, участники, комментарии, приватные идентификаторы объектов,
история проекта и остальные загруженные файлы не возвращаются. Неизвестные поля
документа отбрасываются. Любой текст, явно помещённый автором на холст, публикуется.

Fabric StaticCanvas отображает снимок без редактирования. Разрешены известные
растровые и векторные объекты Fabric, группы, безопасные градиенты и фильтры.
PNG/JPG/WebP должны быть встроены как data URI; сервер проверяет формат, ограничение
пикселей и повторно кодирует их в PNG через sharp. Изображения из раздела загрузок
редактор уже встраивает в документ. Публикация не обращается к внешним URL и не
открывает приватный endpoint файлов для гостей. SVG, внешние URL, шаблоны Pattern,
неизвестные типы и скриптовые значения отклоняются. До 100 разных растровых
изображений и до 18 МБ нормализованного снимка на публикацию.

Ответы имеют `Cache-Control: no-store`, `Referrer-Policy: no-referrer` и
`X-Robots-Tag: noindex, nofollow, noarchive`. Эти заголовки сокращают кэширование
и индексацию, но не заменяют контроль того, кому передана ссылка.

## API

Все изменения требуют сессию владельца и проходят общую проверку Origin.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/projects/:id/publications` | Список ссылок владельца |
| POST | `/api/projects/:id/publications` | Новый токен и снимок сохранённой ревизии |
| PUT | `/api/projects/:id/publications/:token` | Новая неизменяемая версия снимка под той же ссылкой |
| DELETE | `/api/projects/:id/publications/:token` | Окончательный отзыв токена |
| GET | `/api/publications/:token` | Публичный снимок без сессии |

POST/PUT принимают `{ "expiresInDays": 7 }`, `null` для бессрочной ссылки или
альтернативное поле `expiresAt` с ISO-датой. Документ из запроса не используется:
публикация всегда строится из сохранённой сервером ревизии проекта. Успех возвращает
`{ publication: { token, version, sourceRevision, url, expiresAt, ... } }`.
Неизвестная ссылка — 404, отозванная или просроченная — 410.

Таблица `publications` хранит состояние ссылки; `publication_snapshots` хранит
версионированный канонический JSON и SHA-256. Миграции добавляются при запуске
сервера без изменения существующих проектов.

Проверки: `node --test tests/publications.test.mjs` и
`npx playwright test tests/e2e/publications.spec.ts` при работающем приложении.
