# Инструменты редактора

Панель **Инструменты** содержит работающие настройки объектов, коррекцию изображений и вектор SVG. Настройки входят в обычный документ Fabric и участвуют в автосохранении, истории Undo/Redo, версиях и синхронизации совместного редактирования.

## Возможности

- Линейная и радиальная заливка: два цвета, угол линейного градиента, возврат к сплошной заливке. Градиент доступен для фигур и текста; для фотографий используется коррекция изображения. Для линий используется обводка. Группу нужно разгруппировать, чтобы редактировать заливку и обводку отдельных фигур.
- Обводка: цвет, толщина 0–100 px, пунктир; `strokeUniform` сохраняет одинаковую видимую толщину при масштабировании объекта.
- Прямоугольники: радиус скругления ограничен половиной меньшей стороны, сохраняется в `rx`/`ry`.
- Тень: включение, цвет, непрозрачность, размытие и смещения X/Y, включая отрицательные и нулевые значения.
- Фотографии: яркость, контраст, насыщенность, размытие, чёрно-белый фильтр и сепия. Фильтры пересчитываются от исходного изображения без накопления потерь; сброс удаляет только фильтры этой панели. Другие фильтры сохраняются.
- Выравнивание по шести направлениям относительно страницы либо границ нескольких выделенных объектов. Учитывается видимая геометрия после поворота и масштабирования.
- Распределение от трёх объектов с одинаковыми промежутками между границами. Позиции крайних объектов сохраняются. Заблокированные объекты пропускаются. Если объекты перекрываются и суммарный размер превышает доступное место, одинаковые промежутки будут отрицательными.
- Импорт SVG из файла либо вставленного кода, вписывание в текущую страницу и выделение импортированного векторного объекта. Фигуры остаются редактируемыми; несколько элементов образуют группу и могут быть разгруппированы стандартной командой редактора.
- Экспорт текущей страницы в SVG с исходными размерами проекта, независимо от масштаба редактора. Экспорт работает и при доступе только для чтения. Растровые изображения остаются встроенными в SVG растровыми изображениями; SVG-экспорт не превращает фото в вектор.

## Ограничения импорта SVG

Импорт предназначен для векторной графики: базовые фигуры, пути, текст, группы, локальные градиенты и clip paths. Безопасный поднабор проверяется до передачи в парсер Fabric.

Отклоняются скрипты и обработчики событий, HTML/`foreignObject`, анимация, `use`, встроенные и внешние изображения, внешние URL, CSS-импорт и неподдерживаемые CSS-свойства, DTD/сущности XML, инструкции обработки, неизвестные пространства имён, отсутствующие и циклические ссылки. Допустимы только внутренние ссылки вида `#id`. Размер ограничен 2 МБ, количество элементов — 5000, вложенность — 64 уровня; длинные цепочки ссылок также отклоняются. Проверка не выполняет сетевые запросы и не вставляет исходный SVG в DOM страницы.

SVG со сложными фильтрами, масками, встроенными шрифтами, растровыми изображениями или CSS-блоками следует предварительно упростить во внешнем векторном редакторе. Экспорт SVG Fabric может содержать растровые изображения и SVG-фильтры теней, поэтому импорт ограниченного поднабора не является универсальным обратным преобразованием любого экспортированного SVG.

## Проверка

```bash
node --test tests/advanced.test.mjs
npx playwright test tests/e2e/advanced.spec.ts
```

Node-тесты проверяют безопасный SVG, вредоносные варианты, XML/лимиты/циклы ссылок и сериализацию настоящих объектов Fabric. Для них используется Node.js 24, закреплённый в Docker-образе, с нативной поддержкой TypeScript.

Четыре браузерных сценария проверяют сохранение и восстановление эффектов, SVG-экспорт правильного размера, настоящие пиксели PNG после фильтров изображения, безопасный редактируемый SVG-импорт и геометрию распределения/выравнивания. Браузерные тесты требуют работающий сервер из текущих исходников на `TEST_BASE_URL` (по умолчанию порт 8192).

## Интеграция компонента

`src/advanced/AdvancedTools.tsx` экспортирует компонент по умолчанию с параметрами:

```tsx
<AdvancedTools
  canvas={canvas}
  selected={selected}
  readOnly={readOnly}
  onChange={record}
  toast={toast}
  width={project.width}
  height={project.height}
  tick={tick}
/>
```

`onChange` вызывается после успешной правки; компонент запрашивает перерисовку холста. `tick` обновляет значения после внешнего изменения того же объекта, например Undo или синхронизации. Асинхронный SVG-импорт отменяется при размонтировании и повторно проверяет доступ на запись перед добавлением объекта. CSS ограничен контейнером `.advanced-tools`; основной стиль приложения не изменяется.
