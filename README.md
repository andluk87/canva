# Forma — онлайн-студия дизайна

Рабочий первый релиз по [ТЗ](docs/SPECIFICATION.ru.md): независимый браузерный редактор, аккаунты, серверное хранение и экспорт. Это **частичная реализация этапов 1–3**, а не полное соответствие всем 40 разделам ТЗ. Реальные возможности и ограничения перечислены в [матрице](docs/ACCEPTANCE.md).

## Запуск из Git одной строкой

На машине с Git, Docker Engine и Docker Compose v2, из каталога, где ещё нет `canva`:

```bash
git clone --branch main https://github.com/andluk87/canva.git && cd canva && ./scripts/up.sh
```

Сервис слушает **порт 8192** на всех интерфейсах. Откройте адрес своего сервера с портом `8192`. Создайте аккаунт через интерфейс: предустановленных паролей и публичного демо-аккаунта нет. Если репозиторий закрытый, необходим уже настроенный доступ Git к нему.

В существующей копии:

```bash
git pull --ff-only && ./scripts/up.sh
```

Скрипт собирает образ, запускает Compose и проверяет API. В среде без дополнительного CA также можно использовать `docker compose up -d --build`. Если нужен корпоративный CA, задайте путь `FORMA_BUILD_CA` (либо `NODE_EXTRA_CA_CERTS`); сертификат передаётся только как временный build secret, TLS-проверки сохраняются. Проверка вручную: `curl -f http://127.0.0.1:8192/api/health`. Другой порт: `FORMA_PORT=8193 docker compose up -d --build`.

## Что работает

- Регистрация по email и паролю, вход, выход, HttpOnly cookie, хеширование scrypt.
- Личная и общая библиотека проектов, копирование, поиск по названию/папке, избранное, корзина, восстановление, удаление.
- Восемь оригинальных редактируемых шаблонов, шесть форматов, произвольные размеры в px/mm/in (96 DPI).
- Редактор Fabric.js: текст, фигуры, линии, изображения, перемещение, масштабирование, поворот, отражение, прозрачность, несколько объектов, группировка, порядок, блокировка и видимость слоёв, точные координаты, сетка.
- Шрифты, размер, жирный/курсив/подчёркивание, выравнивание, цвета. Двойной клик редактирует текст.
- Многостраничные документы, добавление, копирование, удаление и изменение порядка страниц; просмотр презентации.
- Undo/Redo, автосохранение на сервер, последние 30 версий и восстановление.
- Личная библиотека PNG/JPG/WebP, обработка через Sharp, до 10 МБ / 25 Мп. Изображения в документе встроены, поэтому доступны участникам проекта.
- Экспорт PNG/JPG текущей страницы, многостраничный PDF с растровыми страницами, редактируемый JSON; импорт JSON с совпадающими размерами.
- Бренд-набор с палитрой и системным шрифтом.
- Комментарии и доступ по email существующего аккаунта: владелец, редактор, читатель. Сервер проверяет права. Оптимистическая блокировка предотвращает перезапись устаревшей версией.

## Разработка и проверки

Node.js 24, npm. В облачной задаче используйте существующую копию в `/workspace/canva`; задача уже изолирована, дополнительный worktree не нужен.

```bash
npm ci
npm test
npm run build
npm start
```

Для разработки frontend: `npm run dev`, backend в отдельном терминале: `npm run server`. Vite проксирует `/api` на порт 8192. Если Docker уже использует 8192, предварительно остановите его командой `docker compose stop`.

Браузерные сценарии против запущенного приложения:

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

Если установлен `/usr/bin/chromium`, конфигурация использует его. `TEST_BASE_URL` меняет адрес приложения. Тесты создают собственные аккаунты с уникальными email. Серверные тесты используют временную БД и удаляют её после выполнения. E2E-данные остаются в тестовом экземпляре; запускайте на отдельном томе при проверке production.

## Данные и эксплуатация

База SQLite (WAL) и обработанные изображения находятся в именованном томе `canva_forma_data`, путь в контейнере `/app/data`. `docker compose down` сохраняет том; **`docker compose down -v` уничтожает данные**. Контейнер работает под пользователем `node`, без Linux capabilities, с healthcheck и ротацией логов.

Для резервной копии без риска рассогласования остановите единственный сервис, скопируйте весь каталог данных и снова запустите:

```bash
docker compose stop forma
mkdir -p backups
docker cp "$(docker compose ps -aq forma):/app/data/." "backups/forma-$(date -u +%Y%m%dT%H%M%SZ)"
docker compose start forma
```

Восстановление: остановить сервис, сохранить текущие данные отдельно, скопировать содержимое копии в `/app/data`, восстановить владельца UID/GID 1000, запустить и проверить `/api/health` и вход. Регулярные резервные копии и автоматическое восстановление пока не настроены.

Для публичной эксплуатации нужен reverse proxy с HTTPS. Установите `COOKIE_SECURE=true` при обслуживании через HTTPS. Не включайте этот флаг для обычного HTTP, иначе браузер не отправит cookie. Секреты внешних провайдеров для текущих функций не требуются. SQLite предполагает один экземпляр backend; горизонтальное масштабирование не реализовано.

## Ограничения релиза

Не реализованы AI, платежи, OAuth/SSO/2FA/email-подтверждение/сброс пароля, realtime Yjs, приглашения по почте, видео/аудио, документы/таблицы, сайты, маркетплейс, enterprise, мобильные приложения и офлайн-синхронизация. Общий доступ требует обновления страницы для получения чужих изменений. При конфликте сохранения нужно сохранить локальную копию JSON и перезагрузить проект; автоматического слияния нет.

PDF содержит растровые страницы, не выделяемый текст; CMYK, PDF/X, печатные вылеты и встраивание шрифтов не реализованы. Доступны системные шрифты браузера; загружаемые шрифты и SVG-импорт отсутствуют. Масштаб ограничен 5–200%, страницы — 100, объекты на странице — 2000, размеры — 100–6000 px. Отдельного редактора векторных путей нет. Полноценное соответствие Canva, промышленная безопасность и нагрузочные SLA не подтверждены.
