# Forma — онлайн-студия дизайна

Релиз **0.3.0** по [ТЗ](docs/SPECIFICATION.ru.md): браузерный редактор с совместной работой, расширенными инструментами, массовым созданием из CSV, публичными снимками, TOTP и локальным сохранением открытых проектов. Это **частичная реализация этапов 1–3**, а не полное соответствие всем 40 разделам ТЗ. Реальные возможности и ограничения перечислены в [матрице](docs/ACCEPTANCE.md).

## Запуск из Git одной строкой

На машине с Git, Docker Engine и Docker Compose v2, из каталога, где ещё нет `canva`:

```bash
git clone --branch main https://github.com/andluk87/canva.git && cd canva && ./scripts/up.sh
```

Сервис слушает **порт 8192** на всех интерфейсах. Откройте адрес своего сервера с портом `8192`. Создайте аккаунт через интерфейс: предустановленных паролей и публичного демо-аккаунта нет. Если репозиторий закрытый, необходим уже настроенный доступ Git к нему.

В существующей копии:

```bash
git pull --ff-only && ./scripts/up.sh
```

Скрипт собирает образ, запускает Compose и проверяет API. В среде без дополнительного CA также можно использовать `docker compose up -d --build`. Если нужен корпоративный CA, задайте путь `FORMA_BUILD_CA` (либо `NODE_EXTRA_CA_CERTS`); сертификат передаётся только как временный build secret, TLS-проверки сохраняются. Проверка вручную: `curl -f http://127.0.0.1:8192/api/health`. Другой порт: `FORMA_PORT=8193 docker compose up -d --build`.

## Что работает

- Регистрация по email и паролю, вход, выход, HttpOnly cookie, хеширование scrypt. В настройках — имя профиля, смена пароля, список и отзыв сеансов, двухфакторная защита TOTP с одноразовыми резервными кодами.
- Личная и общая библиотека проектов, копирование, поиск по названию/папке, избранное, корзина, восстановление, удаление.
- Восемь оригинальных редактируемых шаблонов, шесть форматов, произвольные размеры в px/mm/in (96 DPI).
- Редактор Fabric.js: текст, фигуры, линии, изображения, перемещение, масштабирование, поворот, отражение, прозрачность, несколько объектов, группировка, порядок, блокировка и видимость слоёв, точные координаты, сетка.
- Шрифты, размер, жирный/курсив/подчёркивание, выравнивание, цвета. Двойной клик редактирует текст.
- Панель «Инструменты»: линейные/радиальные градиенты, обводка и пунктир, скругление прямоугольников, тени, выравнивание и равномерное распределение. Для изображений — яркость, контраст, насыщенность, размытие, чёрно-белый фильтр и сепия.
- Многостраничные документы, добавление, копирование, удаление и изменение порядка страниц; просмотр презентации.
- Локальный Undo/Redo на основе Yjs, автосохранение на сервер, последние 30 контрольных версий и восстановление.
- Личная библиотека PNG/JPG/WebP, обработка через Sharp, до 10 МБ / 25 Мп. Изображения в документе встроены, поэтому доступны участникам проекта.
- Экспорт PNG/JPG/SVG текущей страницы, многостраничный PDF с растровыми страницами, редактируемый JSON; импорт JSON с совпадающими размерами и проверенного поднабора векторного SVG.
- Бренд-набор с палитрой и системным шрифтом.
- Массовое создание: текстовые переменные `{{имя}}` на всех страницах и внутри групп, предпросмотр CSV, до 50 отдельных проектов за запуск. Создание всего набора выполняется транзакционно.
- Публичные снимки: владелец публикует сохранённые страницы по случайной ссылке, задаёт срок, обновляет снимок или отзывает ссылку. Гость просматривает снимок без аккаунта; приватные изменения не публикуются автоматически.
- PWA и офлайн: оболочка production-сборки кэшируется service worker, ранее открытые проекты и изменения Yjs сохраняются в IndexedDB отдельно для каждого аккаунта. После возвращения сети правки отправляются серверу с повторной проверкой доступа.
- Комментарии и доступ по email существующего аккаунта: владелец, редактор, читатель. Сервер проверяет права. Изменения синхронизируются через Yjs/WebSocket, видны участники и курсоры; отзыв доступа действует на открытые соединения. Изменения разных объектов и свойств объединяются. Для REST API сохраняется проверка revision.

## Разработка и проверки

Node.js 24, npm. В облачной задаче используйте существующую копию в `/workspace/canva`; задача уже изолирована, дополнительный worktree не нужен.

```bash
npm ci
npm test
npm run build
npm start
```

Для разработки frontend: `npm run dev`, backend в отдельном терминале: `npm run server`. Vite проксирует `/api` на порт 8192. Если Docker уже использует 8192, предварительно остановите его командой `docker compose stop`.

Браузерные сценарии против запущенного приложения:

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

Если установлен `/usr/bin/chromium`, конфигурация использует его. `TEST_BASE_URL` меняет адрес приложения. Тесты создают собственные аккаунты с уникальными email. Серверные тесты используют временную БД и удаляют её после выполнения. E2E-данные остаются в тестовом экземпляре; запускайте на отдельном томе при проверке production.

## Данные и эксплуатация

База SQLite (WAL), обработанные изображения и файл ключа `account-security.key` находятся в именованном томе `canva_forma_data`, путь в контейнере `/app/data`. `docker compose down` сохраняет том; **`docker compose down -v` уничтожает данные**. Контейнер работает под пользователем `node`, без Linux capabilities, с healthcheck и ротацией логов.

Для резервной копии без риска рассогласования остановите единственный сервис, скопируйте весь каталог данных и снова запустите:

```bash
docker compose stop forma
mkdir -p backups
docker cp "$(docker compose ps -aq forma):/app/data/." "backups/forma-$(date -u +%Y%m%dT%H%M%SZ)"
docker compose start forma
```

Восстановление: остановить сервис, сохранить текущие данные отдельно, скопировать содержимое копии в `/app/data`, восстановить владельца UID/GID 1000, запустить и проверить `/api/health` и вход. Сохраняйте SQLite и `account-security.key` вместе: без прежнего ключа существующие TOTP-секреты нельзя расшифровать. Не удаляйте и не регенерируйте этот файл при обновлении. Регулярные резервные копии и автоматическое восстановление пока не настроены.

Для публичной эксплуатации нужен reverse proxy с HTTPS. Установите `COOKIE_SECURE=true` при обслуживании через HTTPS. Не включайте этот флаг для обычного HTTP, иначе браузер не отправит cookie. Секреты внешних провайдеров для текущих функций не требуются. SQLite и WebSocket-комнаты предполагают один экземпляр backend; горизонтальное масштабирование не реализовано. Обратный прокси должен передавать WebSocket Upgrade на `/api/projects/:id/live` и сохранять Host/Origin. Лимиты пилота: 500 соединений на процесс, 20 на пользователя, состояние Yjs до 20 МБ на проект. Присутствие и курсоры не сохраняются, документы и состояние Yjs сохраняются в томе.

## Ограничения релиза

AI, платежи/подписки, OAuth/SSO, подтверждение email и сброс пароля по почте, приглашения по почте, видео/аудио, документы/таблицы, конструктор сайтов, маркетплейс, enterprise и отдельные мобильные приложения не реализованы. TOTP работает без внешнего провайдера; при потере аутентификатора нужен сохранённый резервный код.

Совместные изменения приходят без обновления страницы. Yjs объединяет разные свойства; одновременные правки одного свойства разрешаются детерминированно. Текстовый блок синхронизируется целиком, без посимвольного совместного редактирования. Во время активного ввода текста или перетаскивания входящие изменения отображаются после завершения действия. Отзыв доступа и несовместимый epoch останавливают отправку локальных правок; сохраните их в JSON перед дальнейшими действиями.

PWA и офлайн-перезагрузка требуют **HTTPS либо localhost**, production-сборку и хотя бы одно успешное открытие приложения с сетью для установки service worker. На обычном HTTP по IP удалённого сервера редактор работает онлайн, но браузер не установит service worker. Офлайн доступны только ранее открытые проекты с локальной копией, в том же браузере и аккаунте; это не полная копия серверной библиотеки. Локальные данные зависят от IndexedDB, свободного места и политики браузера. Очистка данных сайта или браузерное удаление хранилища удалит локальные копии. Статус «сохранено на устройстве» отличается от подтверждённого сохранения на сервере. Выход очищает локальные данные аккаунта на этом устройстве; их очистка на чужом отключённом устройстве не гарантируется. Регистрация, управление аккаунтом, CSV-генерация и публикация требуют серверного соединения.

CSV заменяет только текстовые переменные: нет XLSX, формул, подстановки изображений и режима «одна строка — новая страница». Публичная ссылка открывает снимок дизайна, а не созданный сайт; уже скачанный или открытый получателем снимок нельзя удалить удалённо после отзыва ссылки.

PDF содержит растровые страницы, не выделяемый текст; CMYK, PDF/X, печатные вылеты и встраивание шрифтов не реализованы. Доступны системные шрифты браузера; загружаемых шрифтов нет. SVG-импорт поддерживает ограниченный векторный поднабор без скриптов, HTML, внешних ресурсов и встроенных изображений. SVG-экспорт может содержать растровые изображения и фильтры теней, поэтому не каждый экспортируемый файл можно импортировать обратно без упрощения. Масштаб ограничен 5–200%, страницы — 100, объекты на странице — 2000, размеры — 100–6000 px. Отдельного редактора векторных путей нет. Полноценное соответствие Canva, промышленная безопасность и нагрузочные SLA не подтверждены.
